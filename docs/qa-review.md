# QA: проверка реализации

- По исходному CSV для MOW-AER на 01.06.2026 медианный базовый спрос 854, вместимость 900, чувствительность 0,141. При цене 10 000 спрос и продажи равны 713; квантили 0,1 и 0,9 равны 593 и 834. QaApiTest проверяет эти значения, границы продаж, ошибки типов, CSRF и ошибки чтения CSV.
- QaAuthTest проверяет регистрацию, конфликт, неверный пароль, вход, защищённый ресурс и выход. BackendForecastTest отдельно проверяет повреждения и дубликаты CSV.
- Скрипт scripts/verify-http.ps1 проверяет работающий JAR по HTTP. По сообщению ведущего прогон прошёл: health, catalog, расчёт и авторизация. Сохранение пользователя после перезапуска этот сценарий не проверяет.
- Проверка доступности и отображения интерфейса в браузере в рамках этого ревью не проводилась. Это историческое ревью первой версии; утверждение о скрытом кабинете было устаревшим. В редизайне аккаунт открывается в dialog из шапки; новый протокол — frontend-redesign.md.
- Ведущий выполнил clean test bootJar: 8 тестов, 0 ошибок (BackendCsvTest 2, BackendForecastTest 2, QaApiTest 3, QaAuthTest 1). Для Windows с кириллическим путём потребовалась настройка кодировки Gradle. Браузерный расчёт при цене 10 000 подтвердил спрос 713.

- При ревью кода не обнаружено явных SQL-инъекций и вставки пользовательского HTML: JDBC использует параметры, интерфейс — textContent и DOM. Для публичного размещения следует учитывать отсутствие ограничения частоты входа и регистрации; для HTTPS необходимо установить COOKIE_SECURE=true.
