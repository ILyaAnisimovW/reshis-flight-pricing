# Требования и доказательства выполнения

Это карта разработки варианта C из кейса, а не обещание оценки жюри. Аналитический PDF и выполненный ML-ноутбук передаются отдельно в комплекте участника.

| Требование | Реализация | Где проверить |
|---|---|---|
| Собственный прогноз | my_forecast.csv внутри JAR, 155 строк | [Происхождение и формула](data-and-model.md), docs/data-provenance.json |
| Пункт отправления и назначения | Москва фиксирована данными; пять направлений из каталога | GET /api/catalog; форма приложения |
| Дата и цена | Доступные 31 дата; цена JSON number в рублях | [OpenAPI](openapi.json) |
| Серверный расчёт, вариант C | JavaScript отправляет POST /api/calculate; Forecast считает на Java | [C4](c4.md), [пример запроса](integration-guide.md) |
| Медиана и чувствительность | demand = base(0.5) - sensitivity * (price - base_price) | [Данные](data-and-model.md) |

| Указание ИИ | Codex, Sol и Terra, роли и инструменты | [Раскрытие использования ИИ](ai-disclosure.md) |

## Проверки

Исторические протоколы относятся к указанным в них версиям. Публикация документов сама по себе не подтверждает новую сборку или новый деплой. Повторяемые сценарии доступны в `scripts/verify-http.ps1` и `scripts/verify-reference.ps1`; браузерные протоколы и снимки лежат в docs.

Наличие графика не доказывает калибровку квантилей на неизвестных данных. Наличие регистрации не означает OAuth/MFA. Открытый GitHub не заменяет папку сдачи с обязательными PDF, notebook, CSV и общим роликом до трёх минут.
