# Логотип и визуальные проверки

Материалы выбора логотипа и проверок приложения от 14 ноября 2026 года. Варианты созданы встроенным imagegen. На каждом концепте показаны чёрная и белая версии знака.

| Вариант | Идея | Статус |
|---|---|---|
| [01 — самолёт](01-plane.png) | Самостоятельный силуэт самолёта | Рассмотрен |
| [02 — орбита](02-orbit.png) | Самолёт с орбитой и траекторией | Выбран пользователем |
| [03 — аналитика](03-analytics.png) | Самолёт и растущий график | Рассмотрен |

В приложение подключён предоставленный пользователем фрагмент второго варианта: [logo-orbit.png](../../src/main/resources/static/assets/logo-orbit.png). Это исходный PNG, а не вектор. Попытка автоматического удаления фона дала артефакты и не использована. В шапке исходный знак отображается с `mix-blend-mode: screen`, в favicon используется тот же PNG. Форма знака сохранена.

Сайт: https://aviaprognoz.onrender.com/. Проверки API, PostgreSQL и перезапуска описаны в [deployment.md](../deployment.md). Снимки фиксируют состояние на дату проверки и не заменяют проверку текущей доступности.

Рабочие CSV хранятся в `src/main/resources/data/`. Корневая папка `data/` используется локальным запуском и H2; её копии CSV совпали по SHA-256 с исходниками перед исключением папки из Git. Локальная база аккаунтов, runtime, секреты и SSH-ключи в публикацию не входят.
