# Решись — тёмный рабочий инструмент

14.11.2026 · ветка `codex/linear-dark-redesign`, исходная версия `codex/frontend-art-direction`.

## Композиция

Высокая боковая форма заменена горизонтальной панелью. Сверху — контекст редактируемого сценария; ниже — единая рабочая область со сводкой слева и широким графиком справа. Продажи набраны в 76 px, спрос и вместимость — в 24 px. Контекст внутри результата относится именно к полученному ответу; при изменении полей он остаётся прежним вместе с предупреждением об устаревании. Верхний маршрут отражает текущие параметры.

До расчёта показаны инструкция и схема связи цены, спроса и продаж, без фиктивных KPI или временных рядов. Под результатом — три раскрытия: точные квантили, объяснение и источник данных. Формула, CSV, Java, API и авторизация не изменены.

Исходные HTML/CSS/JS и реальные снимки предыдущего приложения сохранены в [linear-dark-before](linear-dark-before/). Более ранние папки screenshots/redesign-2026-11-14 и screenshots/art-direction-2026-11-14 сохранены без изменений.

## Реально просмотренный референс

[Linear](https://linear.app/) открыт во встроенном браузере: просмотрены первый экран и продуктовый интерфейс issue после прокрутки. Наблюдалось изменение содержимого встроенного продуктового примера. Закрытое приложение Linear не исследовалось; измерения его hover-таймингов не заявляются.

Применены пять принципов:

1. Несколько близких чёрных поверхностей разделяют рабочие уровни.
2. Тонкая граница и слабый верхний блик отделяют поверхность без повсеместного свечения.
3. Размер и насыщенность текста задают иерархию: данные важнее метаданных.
4. Компактные инструменты сочетаются с пространством вокруг результата.
5. Короткие переходы связывают состояния; спокойный экран не движется постоянно.

Маркетинговый hero, бренд и тексты Linear не переносились.

## Поверхности, палитра, шрифт

CSS-переменные: canvas #08090B, surface #0D0F12, raised #14171C, interactive #1B1F26, текст #F2F3F5, вторичный #A3A9B3, акцент #B8C3FF. Основная кнопка светлая. График использует тот же холодный акцент; предупреждения имеют словесную подпись и спокойный тёплый оттенок.

Тень сочетает широкую `0 24px 64px #0005`, контактную `0 4px 12px #0006` и внутренний блик `inset 0 1px 0 #ffffff06`. Параметры приподняты над canvas; график занимает более спокойную базовую поверхность. Blur применяется к backdrop диалога.

Локальный Golos Text Variable 400–900, кириллица и знак рубля; OFL 1.1 и авторство сохранены в static/fonts. Нет шрифтового CDN. Числа используют tabular-nums и Intl.NumberFormat ru-RU до двух знаков. Контраст проверенных пар: текст 17,29:1, вторичный 7,60:1, акцент 10,51:1, граница мобильного поля 3,08:1. Это проверка конкретных пар, не полный аудит WCAG. Машинный протокол: [linear-dark-contrast.json](linear-dark-contrast.json).

## Движение

- Вход основной области: opacity и translateY 9 px, 400 ms.
- Контекст результата → продажи → вторичные значения → график: 380 ms с задержками 0/55/110/165 ms, Web Animations API. Появляется сразу настоящее серверное число.
- Линия SVG раскрывается за 620 ms после задержки 165 ms. pathLength нормализует длину штриха; точки, масштаб и конечная геометрия не меняются.
- ResizeObserver перерисовывает SVG только при изменении ширины, сохраняя текущую анимацию при изменении высоты.
- Кнопки: переходы 180 ms, подъём 1 px и press scale(.98).
- Диалог и backdrop: 250 ms, мягкое появление. Закрытие и возврат фокуса происходят сразу.
- Loading: небольшой индикатор на кнопке, без изменения её размеров. Постоянных анимаций в состоянии покоя нет.

prefers-reduced-motion выключает CSS-анимации, переходы, backdrop-анимацию и запуск JS-анимаций. Протокол [frontend-motion-results.json](frontend-motion-results.json) подтверждает реальное промежуточное положение штриха 1 → промежуточное значение → 0, совпадение конечных точек, задержки и отсутствие активного движения после завершения. Сохранена [короткая запись браузера](screenshots/linear-dark-2026-11-14/motion/demo.webm).

## Адаптивность и доступность

Desktop использует горизонтальную панель из четырёх ячеек. На 768 px поля перестраиваются в 2×2; на телефоне ниже них показаны главное число и компактная пара вторичных показателей, затем график. При большом спросе вторичные значения получают дополнительную ширину. Длинные названия переносятся. Размер осей SVG — 12 CSS px, геометрия строится по фактической ширине. Nice ticks сохраняет отрицательные реальные значения и не добавляет отрицательную границу для положительных данных. Таблица даёт все девять квантилей без hover.

Нативные select, inputmode decimal, мобильный размер ввода 16 px. Есть labels, focus, skip-link, aria-live, ошибки поля, aria-busy, возврат к базовой цене. Dialog ограничен высотой 100dvh−32px и прокручивается. Проверены Tab/Shift+Tab/Escape и возврат фокуса. Работа с физической мобильной клавиатурой не проверялась; выполнена имитация низкого viewport 360×500 с фокусом поля и прокруткой диалога.

Для видео нужен официальный FFmpeg из `playwright install ffmpeg`; PLAYWRIGHT_BROWSERS_PATH указывает его локальный кэш. Gradle на этой машине использовал GRADLE_USER_HOME=C:\Users\Ilyan\.gradle.

Ограничения: проверены Chrome и встроенный Chromium, не Safari/Firefox и не физические телефоны. Полный screen-reader/zoom-аудит не выполнялся. Ожидаемые HTTP 401 гостя и искусственные сетевые ошибки присутствуют в протоколе. Публикация, push и замена предыдущих именных комплектов сдачи не выполнялись.
