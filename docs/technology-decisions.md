# Технологические решения

Обновление размещения 14.11.2026: для Render добавлен PostgreSQL JDBC driver (версия из Boot BOM) и обязательный профиль `render`. Neon выбран для хранения пользователей вне эфемерного контейнера, чтобы перезапуски Free Web Service не удаляли аккаунты. H2 остаётся локальным вариантом. Ограничения: внешний сервис, сетевые задержки, лимиты Free; фактические проверки PostgreSQL и деплоя приведены в [deployment.md](deployment.md). Более ранняя строка о неподключённом Render ниже относится к исходному локальному комплекту.

Версии ниже закреплены конфигурацией; статус их фактического исполнения уточняет verification.md. Проверено по официальным требованиям: [Spring Boot 3.5](https://docs.spring.io/spring-boot/3.5/system-requirements.html) поддерживает Java 21 и Gradle 8.x от 8.4; [Gradle 8.14.3](https://docs.gradle.org/8.14.3/release-notes.html) подходит JDK 21. Выбрана поддерживаемая ветка 3.5 с привычными Spring Security/Jackson API, без перехода на новый major ради небольшого проекта.

| Выбор | Задача и соответствие проекту | Простая альтернатива | Издержки и версия |
|---|---|---|---|
| Java | Обязательный язык backend; BigDecimal даёт десятичную арифметику | Python проще для прототипа, но не соответствует заданию пользователя | Нужен JDK; Temurin 21.0.10+7 |
| Spring Boot/Web/Validation | HTTP, JSON, запуск JAR, проверки DTO | Java HttpServer потребовал бы ручной интеграции безопасности | Больше зависимостей и памяти; Boot 3.5.16 |
| Gradle Wrapper | Повторяемая сборка без глобального Gradle | Maven Wrapper также подходит | Первая загрузка требует сети, кэш занимает место; 8.14.3, SHA дистрибутива закреплён |
| HTML/CSS/vanilla JS | Одна небольшая форма, fetch и состояния | React потребовал бы Node toolchain и сборку | Состояния управляются вручную; стандарты браузера, без стороннего runtime |
| JDBC + H2 file | Постоянное локальное хранение пользователей без установки СУБД | PostgreSQL для многопользовательского хостинга | Нужен постоянный диск, нет горизонтального масштабирования; версия H2 определяется Boot BOM, см. dependency-versions.txt |
| Spring Security + BCrypt + session | Хеши, серверная защита, CSRF, logout | JWT усложнил бы отзыв и хранение в браузере | Сессии теряются при рестарте; BCrypt лимит 72 байта; версии из Boot BOM |
| Apache Commons CSV | Корректный разбор кавычек и заголовков | split по запятой ломает CSV | Дополнительная небольшая зависимость; 1.14.1 |
| SVG + таблица | Девять точек, median и seats без внешнего CDN | Chart.js локально предоставил бы готовые оси/tooltip | Оси и адаптивность реализованы вручную, нет интерактивного zoom; встроенный SVG браузера |
| JUnit + MockMvc | Проверка реального Spring HTTP pipeline и security | Только unit tests не проверили бы фильтры | MockMvc не заменяет браузер, поэтому дополнен JAR HTTP и UI; версии из Boot BOM |
| Один origin | Cookie/CSRF без настройки CORS | Отдельный frontend hosting | Backend обслуживает и статику; CORS не требуется |
| JAR локально; Docker опционально для сервера | Минимальный локальный запуск; переносимая Java среда на хостинге | Установка JDK напрямую на VPS | Docker-конфигурация подготовлена, локальная работа не зависит от него; контейнер отдельно не проверен |
| Render как документированный вариант | Docker, PORT, HTTPS, постоянный диск на платном сервисе | VPS с Java 21 и reverse proxy | Нет подключённого аккаунта; Free не сохраняет H2. Деплой не выполнен, оплаты не производились. [Ограничения](https://render.com/docs/free), [диск](https://render.com/docs/disks), [Docker](https://render.com/docs/docker) |

BigDecimal читает сохранённые десятичные значения, а не исправляет округление уже экспортированного ML CSV. Отображение в браузере через Number ограничено двумя знаками; эталоны проверяются по неокруглённому серверному ответу. Промышленная точность для цен вне обычных финансовых величин не заявляется.

Редизайн14.11.2026 сохраняет технологический выбор: ResizeObserver строит SVG по реальной ширине (текст12CSSpx), native dialog и явный цикл Tab обслуживают аккаунт. Node/Playwright1.62.1 нужны только разработчику для тестов; в приложении и демонстрации нет Node или CDN. Издержки собственного SVG — ручной расчёт осей и необходимость тестов на360–1440px; они выполнены, см. frontend-redesign.md.
