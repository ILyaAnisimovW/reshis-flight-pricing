# Размещение

Публичного приложения пока нет. GitHub хранит код и запускает CI, GitHub Pages не исполняет Java backend. Подключённой среды Java-хостинга не обнаружено; создание платного сервиса не выполнялось.

Проверены официальные документы Render: [Docker](https://render.com/docs/docker), [web service/PORT](https://render.com/docs/web-services), [HTTPS](https://render.com/docs/tls), [постоянные диски](https://render.com/docs/disks), [Free](https://render.com/docs/free). Free web service имеет 512 MB RAM и эфемерный диск, засыпает при бездействии, не поддерживает persistent disk. Для H2 необходим платный постоянный диск либо смена БД на постоянный внешний PostgreSQL. Бесплатный временный PostgreSQL не равен постоянному хранению сдаваемой версии.

Подготовлен Dockerfile (не обязателен локально). Для хостинга: собрать образ, подключить persistent volume к `/app/storage`, задать `DB_URL=jdbc:h2:file:/app/storage/accounts`, `DB_USER`, `DB_PASSWORD` через секреты сервиса, `COOKIE_SECURE=true`, PORT от платформы. HTTPS завершается на платформе. Команда запуска — `java -jar /app/app.jar`; приложение читает PORT. Диск планировать от 1 GB, память от 512 MB с проверкой под нагрузкой; реальные измерения хостинга не выполнены. Одна реплика для H2, резервное копирование базы после остановки.

На VPS можно запустить обычный JAR под Java 21 и настроить HTTPS reverse proxy. Профиль PostgreSQL в этой версии не реализован и не проверен: потребуются JDBC driver, отдельные настройки, миграция и повторные persistence-тесты. Не подставляйте PostgreSQL URL в текущий JAR.

Для продолжения нужен аккаунт Java-хостинга с подходящим постоянным хранением либо предоставленный VPS. Не передавайте токены в чат. Пока альтернативой сдачи остаётся локальное видео всех функций; сценарий подготовлен, само видео ещё не записано и хостинг не засчитывает.
