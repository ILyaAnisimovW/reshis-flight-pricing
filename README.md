# Решись — авиапрогноз

Работа Анисимова Ильи Васильевича, часть «Разработка», вариант C: браузер обращается к Java API, расчёт выполняется сервером. Пять направлений из Москвы, 31 дата с 01.06.2026 по 01.07.2026. Это учебный прогноз, а не бронирование.

## Запуск

Требуется JDK 21 и интернет для первой загрузки Gradle и зависимостей. Глобальный Gradle, Python и Docker не нужны. Проверяемая среда: Windows, Temurin 21.0.10+7, Spring Boot 3.5.16, Gradle Wrapper 8.14.3. Фактические результаты проверок находятся в [протоколе](docs/verification.md).

Из корня распакованного проекта в PowerShell:

```powershell
.\gradlew.bat clean test bootJar --no-daemon
java -jar build/libs/reshis-app-1.0.0.jar
```

Linux/macOS:

```sh
chmod +x gradlew
./gradlew clean test bootJar --no-daemon
java -jar build/libs/reshis-app-1.0.0.jar
```

Открыть http://localhost:8080. Остановить Ctrl+C. При занятом порте в PowerShell: `$env:PORT='8081'`. Пользователи сохраняются в `data/accounts.mv.db` относительно рабочей папки запуска. При повторном запуске используйте ту же папку или явно задайте DB_URL. База создаётся автоматически, в комплект и Git не входит. Перед переносом базы остановите приложение. Сессии хранятся в памяти и после перезапуска требуют нового входа; учётные записи сохраняются.

## Данные и математика

`src/main/resources/data/my_forecast.csv` — собственный ML-прогноз участника, 155 строк, 30 колонок. Его источник: ранее выполненный ML, LightGBM, чистый повтор `runs/20261108_210239_563007`. ML в приложении не переобучается. `routes.csv` — справочник кейса. SHA-256 и происхождение: [data-provenance.json](docs/data-provenance.json). При старте проверяются схема, числа, уникальность и покрытие данных. Ошибка данных останавливает запуск; подстановки seasonal_forecast нет. CSV включены внутрь JAR и не требуют внешних файлов.

```text
demand = 0.5_base_demand − price_sensitivity × (price − base_price)
sales = min(seats, max(0, demand))
```

Цена в рублях, спрос и продажи — прогнозные пассажиры. `seats` — общая вместимость по расписанию. Используется `BigDecimal` и точное десятичное чтение JSON: вычисления не округляются, интерфейс показывает до двух десятичных знаков (Intl.NumberFormat). Число пассажиров может быть дробным, потому что это оценка. Отрицательный demand сохраняется как результат линейной модели; продажи тогда нулевые. Цена должна быть положительным конечным JSON-числом. Выход за справочные границы разрешён с предупреждением, цена не изменяется автоматически.

Контрольный пример собственного CSV: MOW-AER, 2026-06-01, seats=900, медиана=854, базовая цена=9000, чувствительность=0.141. Цена 10000 даёт demand=713 и sales=713; цена 8000 даёт demand=995 и sales=900.

## API, график, аккаунты

[Контракт и коды ошибок](docs/api-contract.md). GET `/api/catalog` выдаёт маршруты и даты, GET `/api/health` и `/api/ready` — состояние. Сначала получите GET `/api/auth/csrf` с сохранением cookie; передайте возвращённый заголовок с token во всех POST. POST `/api/calculate` принимает `{"route":"MOW-AER","date":"2026-06-01","price":10000}`. Реальный ответ содержит demand=713, sales=713, base_demand=854, seats=900, девять квантилей и warnings. Исполняемые примеры HTTP: `scripts/verify-http.ps1` (PowerShell 7).

График SVG и таблица показывают девять серверных расчётов при одной введённой цене, медиану и seats. Спрос не обрезается до вместимости. Квантили не являются девятью независимыми исходами одинаковой вероятности; покрытие интервала не гарантировано.

Регистрация: логин 3–100 символов латиницы, цифр, `_ . -`, пароль от 8 символов, не более 72 UTF-8 байтов. Вход выполняется отдельно. Spring Security хранит BCrypt-хеш и серверную сессию; cookie HttpOnly, SameSite=Lax, Secure включается `COOKIE_SECURE=true` при HTTPS. CSRF сохраняется. Защищён `/api/account/report` — памятка участника, доступная после входа; публичный прогноз можно проверить без регистрации. Скрытие интерфейса не заменяет проверку сервера. Сессия истекает через 30 минут бездействия. Токены в localStorage не сохраняются.

## Устройство и решения

[Архитектура](docs/architecture.md), [обоснования технологий](docs/technology-decisions.md), [размещение](docs/deployment.md), [демонстрация и защита](docs/demo.md). Один Spring Boot процесс отдаёт страницу и API с одного origin. JDBC и файловая H2 упрощают локальный запуск, серверная сессия использует стандартную защиту Spring Security, SVG не требует CDN. Пределы: один локальный экземпляр, нет восстановления пароля, подтверждения почты и промышленного ограничения частоты запросов. Перед открытием регистрации широкому кругу пользователей нужны эти меры и эксплуатационный мониторинг.

Код и документация подготовлены с помощью Codex: ведущий агент GPT-6.1 Sol согласно назначению пользователя и три роли GPT-6.1 Terra (backend, frontend, QA; модель явно выбрана при запуске). Ассистент написал реализацию и проверки, интегрировал и подготовил комплект. Участник предоставил задачу, собственный ML-прогноз и материалы; самостоятельное освоение и видеозащита пока не подтверждены. Не заявляется, что участник лично написал весь код. [Что объяснить на защите](docs/demo.md).

Материалы кейса принадлежат их правообладателям. Лицензия на чужие CSV не назначается; они включены как необходимые входные материалы решения турнира «Решись». Исходный PDF и ML-модели в репозиторий приложения не включены.

На Windows Gradle использует file.encoding=COMPAT из gradle.properties для корректных путей с кириллицей; исходники компилируются как UTF-8. Если на другой системной кодировке путь не представим, распакуйте проект в простой путь латиницей.
