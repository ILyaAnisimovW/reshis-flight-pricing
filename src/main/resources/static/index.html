Диапазон прогноза спроса

Квантили показывают возможные уровни спроса: например, 0,1 — нижняя оценка, 0,5 — медиана, 0,9 — верхняя оценка. Линия вместимости показывает число мест. Квантили — оценки возможных уровней, а не гарантия результата.
