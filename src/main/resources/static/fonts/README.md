# Golos Text
Источник: https://github.com/google/fonts/tree/main/ofl/golostext
Авторы: The Golos Text Project Authors. SIL Open Font License 1.1 — см. OFL.txt.
Исходный GolosText[wght].ttf преобразован в WOFF2 без изменения рисунка и состава символов посредством fontTools4.68.0/Brotli1.2.1. Ось wght400–900. Проверены кириллицаА/я, ₽ U+20BD и минус U+2212. Один полный вариативный файл обслуживает все начертания и алфавиты; нет зависимости от Google Fonts/CDN во время запуска. CSS font-display:swap, fallback sans-serif.
Конвертер — временный инструмент подготовки ассета, не runtime приложения. OFL сохранена целиком; названия и авторство не присвоены участнику.
